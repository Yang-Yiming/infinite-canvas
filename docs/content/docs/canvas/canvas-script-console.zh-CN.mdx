# 画布脚本控制台

脚本控制台是画布底部的抽屉，用一行语句驱动节点图，适合不想在触摸板上反复拖线、或需要批量生成节点的场景。它不是独立的脚本环境：变量就是节点上的 `alias`，每句语句都会编译成和本地 Agent 相同的画布操作，画布上手动改动也会立刻反映到脚本里。

## 打开与操作

- 点击顶栏的 `>_` 按钮，或按 `Ctrl / Cmd` + `J`，打开或收起控制台。
- 打开时画布区域向上顶起，不会遮挡节点；拖动抽屉顶部横条可以调整高度。
- 上方是历史列表，下方是输入框：回车执行，`Shift` + 回车换行，粘贴多行时按行依次执行。
- 输入框为空或光标在首行 / 末行时，`↑` / `↓` 翻历史；点击历史条目会把原语句填回输入框，点击条目里的 `$变量名` 会定位到对应节点。
- 有变量的节点会在标题旁显示 `$变量名` 徽标，左侧元素列表同样显示。

## 绑定节点和素材

```python
girl = @角色A.png      # @ 触发补全，可搜索画布节点、参考包、我的素材、技能
bgm  = @"背景 音乐"     # 名字里有空格时用引号
ref2 = @#image-1739    # 标题重名时用节点 ID 精确指定
```

`@` 按「节点变量名 → 节点标题 → 我的素材标题 → 技能标题」的顺序匹配，同一层匹配到多个会提示候选。素材被引用时会先落成画布节点再连线，技能只能用在 `skill=` 参数里。

## 文本和参考包

```python
style = "赛博朋克，霓虹夜景，35mm"   # 新建文本节点
cast  = [girl, ref2, bgm]           # 新建参考包节点并连入这些参考
```

变量已经指向文本节点时，再次赋值会**原地更新**它的内容；已经指向参考包时会**原地重连**（删掉旧入边、连上新入边）。

## 触发生成

```python
p    = txt(cast, "写一段{girl}跳舞的分镜提示词", skill=@分镜技能)
shot = img(girl, p, style, size="2:3", n=2)
clip = vid(shot, "镜头缓慢推进", seconds=5)
vo   = aud("欢迎来到夜之城", voice="alloy")
img(girl, "换成红色外套")            # 不赋值时自动命名 img1、txt2…
```

- **回车只建节点，不会调模型**：节点会带上提示词、参数和输入连线，并自动选中、展开它的提示词面板，你可以改完提示词/参数后点面板里的「生成」发送。
- 位置参数里的节点、参考包、素材会连成生成输入，字符串按顺序用换行拼成提示词。
- 提示词里的 `{变量名}` 和 `@变量名` 都会变成真正的引用：文本节点用 `{p}` 会替换成它的内容，图片 / 视频 / 音频用 `{girl}` 或 `@girl` 会替换成它的引用编号（如「图片1」）并自动加入输入，不需要手工记编号；`@` 写错了（邮箱、`@user` 等解析不到的名字）会保持原样，不会报错。
- 生成始终新建输出节点；同名变量再次生成时，旧节点会改名为 `name_1`、`name_2`…，新节点接管原变量名，旧结果仍然可以引用。
- 想直接跑，在语句末尾加 `!`：`shot = img(girl, style)!` 会建完节点立刻生成；单独写 `shot!` 则对已有节点立即生成（用节点当前的提示词、参数和输入，并先等它的上游生成完成）。
- 引用了还在生成的变量时，这句话会等它完成再执行；上游失败会提示「依赖 xxx 生成失败」。

关键字参数（写错参数名或用于不支持的类型会直接报错）：

| 参数 | 适用 | 说明 |
| --- | --- | --- |
| `model` | 全部 | 模型，如 `model="default::gpt-image-2"` |
| `skill` | `txt` | 技能素材，`skill=@分镜技能` |
| `effort` | `txt` | 推理强度 |
| `n` | `txt` / `img` | 生成份数 |
| `size` | `img` / `vid` | 尺寸或比例，如 `size="2:3"` |
| `quality` | `img` | 质量 |
| `seconds` / `steps` | `vid` | 时长和采样步数 |
| `voice` / `speed` / `format` | `aud` | 音色、语速、格式 |

## 重跑

```python
shot!              # 用 shot 节点当前的提示词、参数和输入立即生成
shot = img(girl, style)!   # 建节点并立刻生成
```

`shot!` 不会新建节点，适合在面板里微调完提示词后直接跑，也适用于手动创建的生成节点（但正在生成中的节点会提醒你等它完成）。想拿回当初那条语句，用 `:replay shot` 把它填回输入框。

## 命令

| 命令 | 作用 |
| --- | --- |
| `:ls` | 列出当前所有变量（名字、类型、状态、标题） |
| `:focus 名称` | 定位并选中该节点 |
| `:mv 旧名 新名` | 改变量名 |
| `:unname 名称` | 去掉变量名，不删节点 |
| `:rm 名称...` | 删除节点（可 `:undo` 撤销） |
| `:replay 名称` | 把生成该节点的原语句填回输入框，确认后回车执行 |
| `:undo` | 撤销最近一次脚本操作 |
| `:clear` | 清空控制台历史，不动画布 |
| `:help` | 打印语法速查 |

## 脚本片段

把常用写法存成带参数的片段，之后像函数一样调用：

```python
:def cover(src, text) img({src}, "{text}", size="2:3")
hero = cover(girl, 夜色)
:defs      # 列出所有片段
:del cover # 删除片段
```

- 片段只保存一段**表达式**模板，赋值由调用方写（`hero = cover(...)`）。
- `{参数}` 在字符串里插入文本，在表达式位置插入调用方的原文；因此 `cover(girl, 夜色)` 会展开成 `img(girl, "夜色", size="2:3")`。
- 片段可以互相调用，同名 `:def` 会覆盖旧定义；片段保存在浏览器本地，不随画布导出或同步，补全里也会作为函数出现。

## 导出选中子图

选中若干节点后右键 →「导出为脚本」，会把选中节点和它们依赖的上游节点按顺序重建为语句，作为草稿追加到输入框末尾（**只填草稿，按回车才执行**）。

- 生成节点会带上提示词和 `model` / `size` / `n` 等参数，图片、视频、音频文件本身无法重建成语句，会保留为 `@"标题"` 引用。
- 导出的生成语句同样不会自动执行；需要立即生成时在行尾补一个 `!`，或者按回车建好节点后在面板里发送。
- 分组节点和生成配置节点会在开头的注释里说明跳过；从配置节点取参数的生成节点，导出时只带节点自身记录的参数。

## 把节点插入脚本

`Alt` + 点击节点，或右键菜单「插入到脚本」：会先按类型自动命名（`img3`、`txt2`…），再把变量名插入输入框光标处，控制台会自动打开。

## 注意事项

- 变量名在同一个画布内唯一；删除节点等于删除变量，脚本再引用时会提示「未定义的变量」。
- 回车执行语句只会创建/更新节点，不会调用模型；只有行尾 `!`、`name!` 或者在节点面板里点「生成」才会真正生成并消耗额度。
- 不写 `n` 时图片张数沿用画布当前的生成张数设置。
- `:undo` 只能撤销最近一次脚本操作，并且与本地 Agent 共用同一份撤销快照；画布自身的 `Ctrl / Cmd` + `Z` 不受影响。
- 历史记录随画布保存；刷新后仍在生成中的条目会按节点实际状态判定为完成或失败。
